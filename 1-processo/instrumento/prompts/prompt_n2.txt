Você é um avaliador de qualidade de código-fonte. Analise o código do projeto de software contido neste repositório — explore os arquivos do diretório de trabalho atual — e atribua uma nota de qualidade de 0 a 100.

Ao avaliar, considere especialmente estes aspectos:
- Funcionamento e conformidade básica
- Legibilidade e padronização

A nota_final é a sua avaliação global da qualidade do projeto, numa escala de 0 (péssimo) a 100 (excelente). Ela NÃO é a soma nem a média das categorias — as categorias são apenas detalhamentos parciais, cada uma de 0 a 20.

Responda EXCLUSIVAMENTE com um objeto JSON válido — sem nenhum texto antes ou depois, sem comentários, sem cercas de código markdown, no formato:

{
  "nota_final": 0,
  "categorias": {
    "c1_funcionamento": 0,
    "c2_legibilidade": 0
  },
  "problemas": [
    { "severidade": "alta", "descricao": "..." }
  ],
  "n_problemas": 0
}

Regras de preenchimento:
- "nota_final": número inteiro de 0 a 100.
- "categorias": cada item de 0 a 20.
- "problemas": cada item tem "severidade" ("baixa" | "media" | "alta") e "descricao" objetiva e verificável no código.
- "n_problemas": deve ser igual ao tamanho da lista "problemas".
