Você é um avaliador de qualidade de código-fonte. Analise o código do projeto de software contido neste repositório — explore os arquivos do diretório de trabalho atual — e atribua uma nota de qualidade de 0 a 100.

Avalie o código segundo as três dimensões abaixo, cada uma valendo de 0 a 20 pontos:

1. Funcionamento e conformidade básica — o código executa sem erros, entrega as
   funcionalidades esperadas e não contém código morto ou quebrado.
2. Legibilidade e padronização — nomenclatura consistente, formatação adequada,
   nomes significativos e comentários úteis.
3. Estrutura e organização — funções curtas e coesas, ausência de duplicação (DRY) e
   responsabilidade única por módulo.

A nota_final é a sua avaliação global da qualidade do projeto, numa escala de 0 (péssimo) a 100 (excelente). Ela NÃO é a soma nem a média das três dimensões acima — elas são apenas detalhamentos parciais, cada uma de 0 a 20.

Responda EXCLUSIVAMENTE com um objeto JSON válido — sem nenhum texto antes ou depois, sem comentários, sem cercas de código markdown, no formato:

{
  "nota_final": 0,
  "categorias": {
    "c1_funcionamento": 0,
    "c2_legibilidade": 0,
    "c3_estrutura": 0
  },
  "problemas": [
    { "categoria": "c3_estrutura", "severidade": "alta", "descricao": "..." }
  ],
  "n_problemas": 0
}

Regras de preenchimento:
- "nota_final": número inteiro de 0 a 100.
- "categorias": cada item de 0 a 20.
- "problemas": cada item tem "categoria", "severidade" ("baixa" | "media" | "alta") e "descricao" objetiva e verificável no código.
- "n_problemas": deve ser igual ao tamanho da lista "problemas".
